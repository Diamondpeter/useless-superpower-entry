A one-line entry for the "One Line, Zero Use: The Useless Superpower Sprint" bounty. The program writes a single 104-character line about a hilariously useless superpower — teleportation with a three-foot range — to `/output/entry.txt`, after checking it fits the gate's 200-character limit.

## Run it

```sh
python3 main.py
```
